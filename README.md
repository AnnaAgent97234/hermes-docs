# hermes-docs

> Documentation, guides, and reference notes.

This repository hosts living documentation — the "why", the "how", and the
copy-paste patterns that come with it.

## Index

| Section      | What's there                                        |
| ------------ | --------------------------------------------------- |
| `guides/`    | Task-oriented walkthroughs (start → finish)         |
| `reference/` | Feature and API reference                           |
| `recipes/`   | Copy-paste patterns and worked examples             |

> These directories are added as content lands — the index fills in as the
> repository does.

## Getting started

- Pick the directory that matches what you're after.
- Every guide starts with **what** it solves and ends with **how** to do it.
- No prerequisites beyond the thing being documented — state them up front if
  there are any.

## Contributing

1. Fork and branch from `main`.
2. Keep files **Markdown-only** so they render anywhere.
3. Open a PR describing what changed and why.
4. Small, focused docs beat large ones — one topic per file.

## Conventions

- One topic per file.
- `kebab-case` filenames.
- A one-line "why this exists" at the top of every doc.
- Code blocks always labeled with the language.
- Front matter (YAML) for metadata when it helps discovery.
